# Programmering i TypeScript, DT208G
## Laboration 4 - Angular 2

Uppgiften går ut på att skapa en Angular-applikation som hämtar kurser från 
en URL med hjälp av HttpClient. Kurserna ska presenteras i en tabell och logiken hanteras
via service-klasser. Applikationen ska också ha en sorterings- och sökningsfunktionalitet.
